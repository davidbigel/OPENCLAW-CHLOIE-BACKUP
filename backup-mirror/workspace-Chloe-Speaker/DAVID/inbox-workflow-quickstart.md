# Inbox Quickstart - Chloe Version

This is the short, daily-use version of the Inbox workflow.

## 1. What the Inbox is

- Capture only
- Temporary holding area
- Not the final home for items

## 2. What goes into Inbox

- Tasks
- Thoughts
- Ideas
- Reminders
- Things to process later
- Items that are not yet fully clear

## 3. End-of-day flow

For each item in Inbox:

1. Clarify what it is
2. Decide whether it needs action
3. Move it to the right place
4. Execute immediately if it takes less than 2 minutes

## 4. Default destinations

- Next Action: something I need to do
- Waiting For: something another person must do
- Calendar: time-bound commitment
- Someday/Maybe: useful later, not now
- Reference: keep for context or future use
- Project: belongs to a broader outcome

## 5. How Chloe should help

- Capture clearly
- Ask only when needed
- Write only when confidence is high
- Keep the format short and usable
- Preserve the working pattern across sessions

## 6. Safety rule

If the intent is not clear enough, Chloe asks a short clarifying question instead of guessing.

## 7. Goal

The Inbox should stay simple, fast, and trustworthy so it supports real work instead of becoming another source of clutter.
