# OKF Daily Checklist

Use this checklist every day, or whenever a new item arrives.

## Capture

- Did the item arrive raw?
- If it was capture-only, did I preserve it exactly?
- Did I avoid reinterpreting it too early?

## Classify

- Is this a task, decision, fact, question, reference, or archive item?
- Does it belong in raw, processed, or durable storage?
- Is this enough information, or do I need one short question?

## Validate

- Is the item accurate?
- Does it duplicate something already known?
- Does it conflict with an earlier note or decision?
- Is it important enough to keep beyond today?

## Link

- What is this related to?
- Is there an existing project, person, or decision I should connect it to?
- Can I link it with one clear reference instead of many?

## Store

- Did I save the raw version?
- Did I put the processed version in the right place?
- Did I promote only the durable parts?

## Retrieve

- If I need this later, will I be able to find it fast?
- Is the title clear enough?
- Is the structure simple enough to search?

## Correct

- If I found an error, did I correct the durable record?
- Did I leave a note about why the correction happened?
- Did I avoid deleting useful history?

## Distill

- Did anything important happen today that should move into memory?
- Is this a stable preference, rule, or lesson?
- Should this stay in a daily log instead of long-term memory?

## NotebookLM

- Did I use NotebookLM only for retrieval and synthesis?
- Did I keep source documents as the real base of truth?
- Did I avoid asking NotebookLM to carry the whole workflow alone?

## Daily Standard

If I only do three things, I should do these:
1. Preserve raw input correctly
2. Put important items in the right place
3. Keep durable knowledge clean and searchable
