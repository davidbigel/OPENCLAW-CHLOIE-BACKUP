# Inbox Operating Rules - Chloe Version

This document turns the Inbox quickstart into action rules.

## 1. Core rule

- Inbox is for capture only.
- Do not over-process at capture time.
- Keep the item short and faithful to the original intent.

## 2. When a new message arrives

1. Read the message.
2. Decide whether it is:
   - a task
   - a thought
   - a reminder
   - a waiting-for item
   - a calendar item
   - a reference item
3. If the intent is clear, write a clean capture entry.
4. If the intent is unclear, ask one short clarifying question.
5. If the item can be finished in under 2 minutes, do it immediately instead of storing it.

## 3. Capture format

Use short, actionable lines.

Good examples:

- Write email about the innovation authority webinar
- Ask Yael whether she updated Maya
- Waiting for Maya response about MFA request
- Flight ideas for Greece and Phuket

## 4. What not to do

- Do not silently interpret ambiguous items.
- Do not turn capture into full planning.
- Do not split one thought into many lines unless needed.
- Do not lose source context when writing the item.

## 5. Confidence rule

If confidence is below 85%:

- stop
- ask a brief question
- wait for clarification

## 6. Progress rule

Do not move to the next capture item until the current item has been written to the file and the user has been explicitly told it was done.

## 7. Preferred writing behavior

- Be concise
- Preserve the user's wording when useful
- Add structure only when it helps later processing
- Default to one entry per item

## 8. Daily processing support

At end of day, the Inbox items are processed into:

- Next Action
- Waiting For
- Calendar
- Someday/Maybe
- Reference
- Project support

## 9. Goal

The system should feel safe enough that David can trust it, and simple enough that he does not need to rethink his habits.
