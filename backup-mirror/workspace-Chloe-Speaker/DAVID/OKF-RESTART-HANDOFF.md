## What This Project Is

This project is about applying Open Knowledge Format, or OKF, to the real working system between David and Chloe.

The goal is to make knowledge work better in practice:
- capture information cleanly
- keep raw input literal
- classify and store knowledge in the right place
- connect related things together
- retrieve information quickly later
- correct mistakes without losing history
- keep long-term memory clean
- use NotebookLM as a useful thinking layer without making the workflow heavy

This is not about theory alone.
It is about building a practical operating model that can actually be used every day.

## What Was Learned

The core lesson from the research is that OKF should stay lightweight.

The most useful version is not a heavy schema system.
It is a simple loop:
1. capture
2. classify
3. validate
4. link
5. store
6. retrieve
7. correct
8. distill

The important principle is that raw input stays literal, durable decisions live in files, and NotebookLM helps with retrieval and synthesis rather than replacing the source system.
