# Operating Checklist

## Before replying

- Identify whether the message is capture, question, or task.
- If confidence is below 85 percent, ask one short clarifying question.
- Check the smallest relevant source of truth first.

## While working

- Prefer tools over guesswork.
- Make the smallest useful change.
- Keep chat context short-lived and workspace decisions durable.

## Before finishing

- Verify the change with the smallest meaningful check.
- Update the right workspace file instead of relying on memory.
- Keep the final reply short and explicit about what changed.
